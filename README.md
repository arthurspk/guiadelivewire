## :dart: O guia para alavancar a sua carreira

> Livewire é o framework full-stack reativo oficial do ecossistema Laravel: permite construir interfaces dinâmicas — atualização de tela sem reload, formulários reativos, validação em tempo real — escrevendo praticamente só PHP e Blade, sem montar uma API JavaScript separada. Criado por Caleb Porzio e hoje mantido junto com a equipe do Laravel, chegou à versão 4.x com uma arquitetura de "Islands" que isola partes da página para atualizar só o necessário. É a base de ferramentas populares como Filament e Flux UI, e a porta de entrada mais rápida para quem já sabe Laravel e quer interatividade sem aprender um framework JS inteiro. Este guia reúne documentação oficial, cursos gratuitos e pagos, livros, canais, ferramentas do ecossistema (Alpine.js, Volt, Flux UI, Filament) e um capítulo sobre usar IA na prática com Livewire — tudo verificado, com prioridade para conteúdo gratuito e em português.

**Trilha resumida** (siga na ordem; cada etapa tem recursos nas seções abaixo):

1. **Fundamentos de PHP e Laravel** — Livewire é um pacote Laravel; domine rotas, controllers, Blade e Eloquent antes de começar.
2. **Instalação e primeiro componente** — `composer require livewire/livewire`, crie um componente com `php artisan make:livewire` e renderize com `<livewire:nome />`.
3. **Properties e actions** — como sincronizar dados entre PHP e o navegador (`wire:model`) e reagir a cliques (`wire:click`).
4. **Formulários e validação** — `wire:submit`, `Form Objects` e as regras de validação do Livewire.
5. **Lifecycle hooks e propriedades computadas** — `mount`, `updated`, `computed()` para lógica reativa.
6. **Componentes aninhados e comunicação por eventos** — dividir a interface em componentes menores que conversam entre si.
7. **Alpine.js e JavaScript** — como e quando sair do PHP e usar Alpine para interações puramente visuais.
8. **Testes** — testar componentes Livewire com Pest ou PHPUnit.
9. **Islands e performance** — a arquitetura de ilhas da versão 4.x para atualizar só pedaços da página.
10. **Ecossistema** — Volt (API funcional), Flux UI (componentes prontos) e Filament (painéis administrativos construídos sobre Livewire).

## 🚀 Por onde começar
1. **Tenha um projeto Laravel rodando** e instale o Livewire — [Installation](https://livewire.laravel.com/docs/4.x/installation) traz o passo a passo oficial (`composer require livewire/livewire`).
2. **Faça o Quickstart oficial** — [Quickstart](https://livewire.laravel.com/docs/4.x/quickstart) — cria um contador reativo em poucos minutos e já mostra o ciclo completo PHP ↔ navegador.
3. **Aprenda Components e Properties** — [Components](https://livewire.laravel.com/docs/4.x/components) e [Properties](https://livewire.laravel.com/docs/4.x/properties) — como criar um componente e sincronizar estado.
4. **Aprenda Actions** — [Actions](https://livewire.laravel.com/docs/4.x/actions) — como responder a cliques e eventos do usuário sem escrever JavaScript.
5. **Assista a um curso em vídeo em português** em paralelo à documentação — veja [🔤 Sites e cursos](#-sites-e-cursos-para-aprender-livewire) abaixo.
6. **Entenda quando usar Alpine.js** — [Alpine](https://livewire.laravel.com/docs/4.x/alpine) — para interações que não precisam de round-trip ao servidor.
7. **Construa algo real com o Laravel Bootcamp** — [laravel.com/learn](https://laravel.com/learn) — tutorial oficial que constrói uma aplicação de chat, com opção de usar Livewire.
8. **Explore o ecossistema** — instale o [Flux UI](https://fluxui.dev/) ou o [Filament](https://filamentphp.com/) para ver Livewire em produção, em componentes prontos e em um painel administrativo completo.

Seu primeiro componente em poucos comandos:

```bash
composer require livewire/livewire
php artisan make:livewire contador
```

## 🤖 IA na prática
Livewire mistura PHP e Blade numa única classe, o que confunde assistentes de IA treinados majoritariamente em stacks separadas de back-end/front-end: é comum a IA sugerir buscar dados via `fetch`/Axios como se fosse um componente React, quando o padrão idiomático do Livewire é simplesmente uma property pública sincronizada. Ainda assim, para tarefas repetitivas — gerar um componente CRUD, um Form Object ou um teste Pest — a IA economiza bastante tempo.

**Para aprender**
- Peça para a IA explicar a diferença entre uma `action` e uma `computed property` no seu próprio código, com exemplos do componente que você está construindo.
- Peça exercícios de refatoração: transforme um componente com muita lógica na view em um com Form Object e veja a IA justificar o porquê.
- Peça para a IA gerar testes Pest para um componente Livewire existente — é uma forma rápida de aprender a sintaxe de testes específica do framework (`Livewire::test(...)`).
- Peça para comparar uma solução com `wire:model.live` (síncrona, mais chamadas ao servidor) com `wire:model` puro (só no submit) e explicar o trade-off de performance.

**Para trabalhar**
- Use GitHub Copilot, Cursor ou Claude Code para gerar o esqueleto de componentes Livewire (classe + view Blade) a partir de uma descrição do comportamento esperado.
- Experimente o [Laravel Boost](https://laravel.com/docs/13.x/boost), pacote oficial que dá ao assistente de IA contexto real sobre as versões instaladas do Laravel, Livewire e dos demais pacotes do projeto — reduz alucinação de API, que é comum em frameworks que mudam rápido como o Livewire.
- Use o [Laravel MCP](https://laravel.com/docs/13.x/mcp) para expor dados e ações da sua aplicação Livewire a agentes de IA de forma padronizada.
- Depois de aceitar uma sugestão de componente, **rode os testes** antes de confiar — é comum a IA misturar sintaxe de Livewire 2/3 com a 4.x (por exemplo, sugerir `Volt::route` em contextos onde a Island resolveria melhor).
- [GitHub Copilot](https://github.com/features/copilot) — Autocomplete e chat com IA no editor; gratuito para estudantes e com plano free.
- [Cursor](https://cursor.com/) — Editor baseado no VS Code com IA integrada ao fluxo de trabalho.
- [Claude Code](https://code.claude.com/docs/en/overview) — Agente de código no terminal: gera componentes Livewire, escreve testes Pest e explica lifecycle hooks.

**Limites e boas práticas**
- IA **confunde a versão do Livewire** com frequência — sempre confira a sintaxe na documentação da versão instalada (`composer show livewire/livewire`), já que 2.x, 3.x e 4.x têm diferenças relevantes de API.
- Desconfie de sugestões que exponham dados sensíveis como `public` properties sem necessidade — no Livewire, toda property pública é serializada e enviada ao navegador a cada requisição.
- Nunca aceite sugestões que desabilitem a proteção CSRF ou que validem dados só no front-end (Alpine/JS) sem repetir a validação no componente PHP.
- Revise sempre `wire:model` em campos sensíveis (senha, cartão, papel/role de usuário) — vincular a property errada pode criar uma brecha de mass assignment client-side.
